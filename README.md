# 📚 Digital Library Management System

A Digital Library Management System developed using PHP and MySQL.

## Features

- Admin Login
- User Login & Registration
- Add Books
- Edit Books
- Delete Books
- Search Books
- Issue Books
- Return Books
- Borrow History
- User Dashboard
- Admin Dashboard

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Installation

1. Install XAMPP
2. Copy project into htdocs
3. Import database
4. Open

http://localhost/DigitalLibrary
